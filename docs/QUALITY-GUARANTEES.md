# 品質保証台帳

「完了済みの状態を継続的に再検証したい」不変条件の意図・台帳。機械検証できる保証は
テストスイート（実体が強制手段・CI が毎回再検証）で表現し、その意図をここに 1 行登録する。

各行は次の列を持つ:

- **保証したい状態**: 何が満たされ続けるべきか
- **source**: 契機（要件等の安定アンカー。Issue 番号は書かない）
- **強制手段**: 再検証を担うテスト等のポインタ
- **retire 条件**: この保証を台帳から外してよくなる条件
